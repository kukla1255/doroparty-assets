# doroparty-assets

DoroParty(doroparty.com)가 쓰는 니케 초상 WebP 사본입니다. jsDelivr로 제공합니다.

- 경로: `https://cdn.jsdelivr.net/gh/kukla1255/doroparty-assets@<commit>/p/<파일>.webp`
- 파일 이름에 내용 해시가 붙어 있어, 커밋을 고정해 쓰면 1년 캐시해도 안전합니다.
- 갱신은 Dororaid 저장소의 `scripts/site-images/sync_site_images.py`로 합니다.

『승리의 여신: 니케』의 게임 이미지이며, 저작권은 원저작자에게 있습니다.
